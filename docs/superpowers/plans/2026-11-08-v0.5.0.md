# Anchor 0.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship 0.5.0. It adds conditional reads on the secrets list (ETag / 304, with no audit
row for 304) in the server, SDK and CLI, and `anchor run --watch`. It also includes the deferred
OAuth and SDK fixes, a sturdier release pipeline, corrected docs, and tighter tests.

**Architecture:**
- The server hashes the exact JSON body of the secrets list with an HMAC key derived from
  `ANCHOR_ROOT_KEY` (HKDF), and answers 304 to a matching `If-None-Match` before it audits.
- The SDK keeps the tag in its `CacheEntry` and reuses the cached secrets on 304.
- The CLI gets a conditional list call and a child handle it can stop. `run --watch` polls with
  them and restarts one child at a time.
- Everything else is a local fix with its own failing test.

**Tech Stack:**
- pnpm monorepo
- Cloudflare Workers + Hono + D1 (`apps/server`)
- React + TanStack Router (`apps/web`)
- Node SDK built with esbuild (`packages/sdk`, `packages/nestjs`)
- commander CLI (`apps/cli`)
- vitest; `node --test` for `scripts/`

**Spec:** `docs/superpowers/specs/2026-11-08-v0.5.0-design.md`

## Global Constraints

- Communicate with the owner in Vietnamese. Code, comments, commits and docs are in English.
- Commits use `git commit -s`, Conventional Commits, and end with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never log, print or put secret values or tokens in errors, events, audit metadata, debug
  lines or ETags derived without the key.
- Security-sensitive changes (OAuth, the tag key, authz) need tests that prove the failure
  cases.
- The tag is `"<base64url, no padding, of the first 16 bytes of HMAC-SHA-256(etagKey, body)>"`,
  so it matches `/^"[A-Za-z0-9_-]{22}"$/`. `etagKey` = HKDF-SHA-256(`ANCHOR_ROOT_KEY` bytes,
  salt empty, info `anchor/etag/v1`), as a non-extractable HMAC-SHA-256 key.
- A 304 has no body and carries `ETag` and `Cache-Control: no-store`. It writes no audit row.
- SDK: no runtime dependencies; `dist/index.js` stays under 20 KB (20 * 1024 bytes).
- `anchor run --watch`:
  - `--watch-interval` is an integer in seconds: default 30, minimum 5.
  - The restart grace is 10 s, after which SIGKILL is sent.
  - stderr copy, exactly: `Secrets changed; restarting <cmd>`, `Could not check Anchor for
    changes (<message>); keeping the current values`, and `Reconnected to Anchor`.
- `scripts/npm-publish.mjs` checks `npm view` every 30 s, at most 10 times.
- Tests live in each package's layered `test/` tree. Follow
  `apps/docs/src/content/docs/contributing/testing.md`.

## Review Focus

1. **A new SDK or CLI against a 0.4.0 server.** That server sends no `ETag` and ignores
   `If-None-Match`, so it always answers 200. The SDK must never send `If-None-Match` without a
   stored tag, and `run --watch` must not restart when the environment is equal. Pinned in Task 7
   ("no If-None-Match without a stored tag") and Task 10 ("a 200 with an equal environment does
   not restart").
2. **The root key is rotated.** Every client's tag stops matching, and the server must answer a
   normal 200 with a new tag, never an error. Pinned in Task 4 ("an unknown or stale tag gets
   200 with the current tag").
3. **A child that ignores SIGTERM during a restart.** It must get SIGKILL after 10 s, and two
   children must never be alive at once. Pinned in Task 10.
4. **Store entries written by 0.4.0, which have no `etag`.** They must keep working as plain
   entries. Pinned in Task 7.
5. **The child exits on its own while a poll is in flight, or during the restart grace.**
   `anchor` exits with the child's code and starts nothing new. Pinned in Task 10.

**Interfaces:**
- Produces:

import { describe, expect, it } from "vitest";
import { etagFor, etagMatches } from "#src/secrets/etag";

const KEY_A = btoa(String.fromCharCode(...new Uint8Array(32).fill(1)));
const KEY_B = btoa(String.fromCharCode(...new Uint8Array(32).fill(2)));
const sha256Tag = async (body: string) => {
  const d = new Uint8Array(await crypto.subtle.digest("SHA-256", new TextEncoder().encode(body)));
  return `"${btoa(String.fromCharCode(...d.slice(0, 16))).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "")}"`;
};

describe("etagFor", () => {
  it("is a quoted 22-char base64url tag, stable for one body and key", async () => {
    const t = await etagFor({ ANCHOR_ROOT_KEY: KEY_A }, '{"secrets":[]}');
    expect(t).toMatch(/^"[A-Za-z0-9_-]{22}"$/);
    expect(await etagFor({ ANCHOR_ROOT_KEY: KEY_A }, '{"secrets":[]}')).toBe(t);
  });
  it("changes with the body and with the key, and is not an unkeyed hash", async () => {
    const body = '{"secrets":[{"key":"A","value":"hunter2"}]}';
    const a = await etagFor({ ANCHOR_ROOT_KEY: KEY_A }, body);
    expect(await etagFor({ ANCHOR_ROOT_KEY: KEY_B }, body)).not.toBe(a);
    expect(await etagFor({ ANCHOR_ROOT_KEY: KEY_A }, `${body} `)).not.toBe(a);
    expect(a).not.toBe(await sha256Tag(body));
  });
});

describe("etagMatches", () => {
  const t = '"abc"';
  it.each([
    [undefined, false],
    ["", false],
    ['"abc"', true],
    ['W/"abc"', true],
    ['"x", "abc"', true],
    ["*", true],
    ['"abd"', false],
    ["abc", false],
  ])("%j → %s", (header, ok) => expect(etagMatches(header, t)).toBe(ok));
