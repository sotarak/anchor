# Anchor 0.5.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the CLI lists, adds and removes folder imports (with skills and docs that use it); the
secrets table gets a Copy value menu item and one-line rows; the project Overview shows and opens
subfolders.

**Architecture:**
- **CLI:** three `ApiClient` methods over the existing `/imports` endpoints, and a new
  `commands/imports.ts` (address parser + three handlers) registered as `anchor imports`.
- **Web, secrets table:** a menu item that copies through the same read the value cell uses, and
  CSS-only width fixes.
- **Overview:** `getOverview` returns `folders` (per-environment presence from
  `listChildFolders`); the page renders folder rows before key rows in one filtered, paged list.

**Tech Stack:** commander + vitest (CLI); Hono + D1 + Workers vitest pool (server); React 19,
TanStack Router/Query, Tailwind tokens, vitest + Testing Library + msw, Playwright (web).

**Spec:** `docs/superpowers/specs/2026-11-08-v0.5.2-design.md`

## Global Constraints

- No server endpoint, schema or migration change except the additive `OverviewDto.folders` field.
- No new npm dependencies.
- **CLI copy, exact:**
  - group description: `Make a folder show the secrets of another folder (not to be confused with 'secrets import', which loads a file)`
  - `secrets import` description gains: `(not to be confused with 'imports', which links folders)`
  - list: one line per import `<position>  <env>:<path>`; empty: `No imports in <env>:<path>` (stderr)
  - add: `Imported <src> into <env>:<path>` / `Already imports <src> into <env>:<path>`
  - remove confirm: `Stop importing <src> into <env>:<path>?`; done: `Stopped importing <src> into <env>:<path>`
  - remove not found (exit 5): `<env>:<path> does not import <src>`, hint `Its imports: <a>, <b>` or `It has no imports`
  - bad address (exit 2): `Invalid import source '<raw>'`, hint `Use <env>:<path>, e.g. shared:/ or shared:/db`
- **`--json`:** list → `FolderImportDto[]`; add → `{ import, created }`; remove → `{ removed }`.
- **Dashboard copy, exact:** menu item `Copy value`; toast `Value copied`; overview empty title
  `Nothing in this project yet` at `/`, `Nothing in <path> yet` elsewhere; description
  `Secrets and folders you add to any environment show up here, one row per key or folder.`
- Dashboard-ui tokens only; the "Before you finish a UI change" checklist passes on every web diff.
- Secret values never printed by the CLI commands, never put in React state or the DOM by Copy value.
- Every manifest is 0.5.2 at the end.

## Review Focus

1. **One source spelled several ways** (`shared`, `shared:`, `shared:/`, `shared:db/` vs
   `shared:/db`): all normalize before the request and before `remove` compares. Pinned in Task 2.
2. **`add` racing another `add`** (list says absent, POST says 409): ends as `created: false`,
   exit 0. Pinned in Task 2.
3. **Copy value on an imported row** reads through the import (`includeImports=true`), and on a
   non-sensitive row makes no request. Pinned in Task 4.
4. **A folder that exists only in an environment the caller cannot read** never appears in the
   Overview. Pinned in Task 5.
5. **Overview filters with folders**: search matches folder names, Status "Missing somewhere"
   hides a folder present everywhere. Pinned in Task 6.
