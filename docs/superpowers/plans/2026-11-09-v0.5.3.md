# Anchor 0.5.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** close the security gaps chosen from the 0.5.2 review: reserved env names, shell-safe
dotenv export, per-(address, email) login limit, pinned workflow actions, CLI login without a
prefilled code, https-only SDK, Worker security headers, and token/redirect hygiene in clients.

**Architecture:**
- **Shared:** one reserved-name list in `@anchor/shared/env-keys`, bundled into the SDK and
  re-exported as `isReservedEnvKey`; the CLI (`run`, dotenv `export`) and nestjs (`loadAnchorEnv`)
  skip those names with a warning unless opted in.
- **Server:** login counts attempts in a new D1 table keyed by (address, email) and by address,
  replacing the per-account lock on `/auth/login`; one middleware adds security headers to every
  Worker response.
- **Clients and CI:** CLI/SDK refuse redirects, the SDK refuses plaintext http, the CLI login page
  needs a typed code, and every workflow action is pinned to a commit SHA.

**Tech Stack:** TypeScript; Hono + D1 + Workers vitest pool (server); commander + vitest (CLI);
esbuild-bundled SDK/nestjs + vitest; React 19 + TanStack Router + Testing Library + msw (web);
GitHub Actions; `node --test` for `scripts/`.

**Spec:** `docs/superpowers/specs/2026-11-09-v0.5.3-design.md`

## Global Constraints

- No change to crypto, stored data formats, HTTP API request/response shapes, or `wrangler.jsonc`.
  The only migration is the additive `0009_login_attempts.sql`.
- No new npm dependencies.
- Security changes need failure-case tests (CLAUDE.md): every task's tests include the attack.
- Never log or print secret values or tokens; key names may appear in warnings.
- **Reserved names** (case-insensitive; compare `key.toUpperCase()`):
  - exact: `PATH IFS ENV BASH_ENV SHELLOPTS BASHOPTS PROMPT_COMMAND PS4 NODE_OPTIONS NODE_PATH
    NODE_TLS_REJECT_UNAUTHORIZED PYTHONPATH PYTHONHOME PYTHONSTARTUP RUBYOPT RUBYLIB PERL5OPT
    PERL5LIB PERLLIB JAVA_TOOL_OPTIONS _JAVA_OPTIONS JDK_JAVA_OPTIONS GIT_SSH GIT_SSH_COMMAND
    GIT_ASKPASS SSH_ASKPASS GIT_EXEC_PATH GIT_PROXY_COMMAND HTTP_PROXY HTTPS_PROXY ALL_PROXY NO_PROXY`
  - prefixes: `LD_ DYLD_ ANCHOR_ GIT_CONFIG_ NPM_CONFIG_`
- **Copy, exact:**
  - run warning (stderr, `ctx.out.warn`): `Skipped reserved names: <A, B> (pass --allow-reserved to inject them)`
  - export warning: `Skipped reserved names: <A, B> (pass --allow-reserved to write them)`
  - nestjs: `process.emitWarning("Anchor skipped reserved names: <A, B> (set allowReservedKeys to load them)", "AnchorWarning")`
  - login 429 body unchanged: `{ code: "rate_limited", message: "Too many failed attempts, try again later" }`
  - CLI login notice: `Open <origin>/cli/login and enter the code <XXXX-XXXX>`
  - web code form helper: `Type the code from your terminal yourself. Never enter a code someone sent you.`
  - SDK http refusal (`AnchorError(0, "config", …)`): `Anchor API URL must use https:// (http:// only for localhost, 127.0.0.1 and [::1]); set allowInsecureHttp to override`
  - SDK redirect (`AnchorError(status, "bad_response", …)`): `Anchor at <origin> answered with a redirect (HTTP <status>); use the final address as apiUrl`
  - CLI redirect (`ApiRequestError(status, "internal", …)`): `<origin> answered with a redirect (HTTP <status>); use the final address as the API URL`
- **Worker headers, exact:** `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`,
  `X-Frame-Options: DENY`, `Content-Security-Policy: default-src 'none'; frame-ancestors 'none'`,
  `Strict-Transport-Security: max-age=31536000; includeSubDomains`. The last one is also added to
  the `/*` block of `apps/web/public/_headers`.
- **Login limits:** pair `p|<addr>|<email>` 5 failures; address `i|<addr>` 50 failures; window and
  lock 900 000 ms; `<addr>` = `rateLimitKey(clientIp)` from `apps/server/src/lib/ip.ts`, `-` when
  null (and no `i|` key).
- Every manifest, `apps/server/src/version.ts` and the version pins are `0.5.3` at the end.

## Review Focus

1. **A reserved name in lower or mixed case** (`node_options`, `Path`, `http_proxy`) is skipped
   like the upper-case one. Pinned in Task 1.
2. **`run --watch` after a reserved secret appears mid-run**: the restart's env still skips it and
   warns once for the new set, not on every poll. Pinned in Task 2.
3. **The owner logging in from home while an attacker hammers their email from elsewhere** gets in.
   Pinned in Task 5.
4. **A value that is legal for the dotenv parser but dangerous in a shell** (`"`-free value with
   `$VAR` or a backtick) is refused, while ordinary URLs and random passwords are written exactly as
   in 0.5.2. Pinned in Task 4.
5. **Error responses** (404 route, thrown 500, `/mcp` 401) carry the security headers, not only
   200s. Pinned in Task 6.
